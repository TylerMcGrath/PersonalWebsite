In progress · v1STM32 · FreeRTOS · C

Self-balancing robot

A two-wheeled robot that balances itself with a hard real-time control loop. I'm building it the way I'd validate a production ECU: measured timing, logged disturbances, and a fault-injection rig that tries to break it.

  • ControllerSTM32F407 Discovery running FreeRTOS
  • Control loopIMU read and attitude filter at 200 to 500 Hz, balance PID at 200 Hz
  • EstimationComplementary filter first, then a Kalman filter
  • TelemetryBinary frames over UART to a Raspberry Pi 5, into Prometheus and Grafana
  • Fault injectionArduino Mega as an independent rig
  • Chassis2WD balancing chassis with 520 encoder motors
